# Старый каркас (не используется)

Эти модули остались от первой версии проекта:

- `main.py` — вход, в котором логин и пароль были прописаны в коде;
- `browser_manager.py`, `parser.py` — автоматический обход страниц;
- `student_brain.py` — генерация конспектов без проверки ссылок;
- `timer_service.py` — имитация «человеческого» времени выполнения;
- `notifier.py`, `pdf_exporter.py` — вспомогательные экспорты.

Они выведены из рабочего пути, потому что:

1. хранили пароль в открытом виде;
2. имитировали поведение человека, чтобы обойти контроль времени;
3. не использовали проверку ответов и цитирование источников.

Актуальная реализация — в `src/`:

- `lms_reader.py` — чтение диспейса через браузерную сессию, пароль не хранится;
- `notes.py` — конспекты со ссылками на фрагменты;
- `verification.py` — независимая проверка решений;
- `tutor.py`, `app.py` — оркестратор и интерфейс.

Файлы оставлены только как история. Возвращать их в работу не нужно.
