### Вертикальные асимптоты

Асимптотой кривой называется прямая, к которой неограниченно приближается точка кривой при ее удалении по кривой в бесконечность.

Асимптоты могут быть вертикальными, наклонными (горизонтальные — частный случай наклонной).

Прямая $x={{x}_{0}}$ является вертикальной асимптотой графика функции \(f\left( x \right)\), если хотя бы один из односторонних пределов \(\mathop {\lim }\limits_{x \to {x_0} - 0} f\left( x \right)\) или \(\mathop {\lim }\limits_{x \to {x_0} + 0} f\left( x \right)\) бесконечен. Таким образом, вертикальная асимптота проходит через точку разрыва второго рода.

Пример 1. Найти вертикальные асимптоты функции \(y = {3^{\frac{1}{{x - 4}}}}\).

Р е ш е н и е. Функция элементарная, следовательно, непрерывная на всей области определения.

Точка \(x = 4\) — точка разрыва. Определим ее вид, вычислив односторонние пределы:

\(\mathop {\lim }\limits_{x \to 4 - 0} = \left[ {{3^{\frac{1}{{4 - 0 - 4}}}} = {3^{\frac{1}{{ - 0}}}} = {3^{ - \infty }}} \right] = 0\),

\(\mathop {\lim }\limits_{y \to 4 + 0} = \left[ {{3^{\frac{1}{{4 + 0 - 4}}}} = {3^{\frac{1}{{ + 0}}}} = {3^{ + \infty }}} \right] = + \infty \).

Таким образом, точка \(x = 4\) — точка разрыва второго рода, а прямая \(x = 4\) — вертикальная асимптота (правосторонняя).

### Наклонные и горизонтальные асимптоты

Если существуют конечные пределы \(\mathop {\lim }\limits_{x \to \pm \infty } \frac{{f\left( x \right)}}{x} = k\) и \(\mathop {\lim }\limits_{x \to \pm \infty } \left[ {f\left( x \right) - kx} \right] = b\), то прямая \(y = kx + b\) является наклонной асимптотой кривой \(y = f\left( x \right)\) при \(x \to \pm \infty \).

Если хотя бы один из пределов не существует или равен бесконечности, то кривая \(y = f\left( x \right)\) наклонных асимптот не имеет.

Если угловой коэффициент \(k = 0\), а \(\mathop {\lim }\limits_{x \to \pm \infty } \left[ {f\left( x \right) - kx} \right] = b\) имеет конечное значение, то уравнение асимптоты \(y = b\). Это горизонтальная асимптота — частный случай наклонной.

Асимптоты графика функции \(y = f\left( x \right)\) могут быть разными при \(x \to + \infty \) и \(x \to - \infty \). Поэтому при вычислении \(k\) и \(b\) нужно быть внимательными, и при нахождении горизонтальных и наклонных асимптот следует различать пределы при \(x \to - \infty \) и при \(x \to + \infty \).

### Пример 2

Найти асимптоты кривой \(y = \frac{{{x^2} + 3x + 6}}{{x - 1}}\).

Р е ш е н и е. Функция элементарная, следовательно, непрерывная на всей области определения \(\left( { - \infty ;1} \right) \cup \left( {1; + \infty } \right)\).

Точка \(x = 1\) — точка разрыва. Определим ее вид, вычислив односторонние пределы.

Так как \(\mathop {\lim }\limits_{x \to 1 - 0} \frac{{{x^2} + 3x + 6}}{{x - 1}} = - \infty \), а \(\mathop {\lim }\limits_{x \to 1 + 0} \frac{{{x^2} + 3x + 6}}{{x - 1}} = + \infty \),

то точка \(x = 1\) — точка разрыва второго рода, а прямая \(x = 1\) является вертикальной асимптотой.

Найдем параметры \(k\) и \(b\) наклонной асимптоты:

\(k = \mathop {\lim }\limits_{x \to \pm \infty } \frac{{{x^2} + 3x + 6}}{{x\left( {x - 1} \right)}} = 1\);

\(b = \mathop {\lim }\limits_{x \to \pm \infty } \left[ {\frac{{{x^2} + 3x + 6}}{{x - 1}} - x} \right] =\)\( \mathop {\lim }\limits_{x \to \pm \infty } \frac{{{x^2} + 3x + 6 - {x^2} + x}}{{x - 1}} = \)\(\mathop {\lim }\limits_{x \to \pm \infty } \frac{{4x + 6}}{{x - 1}} = 4\),

следовательно, прямая \(y = x + 4\) — наклонная асимптота.

### Пример 3

Найти асимптоты кривой \(y = \frac{x}{{{x^2} - 1}}\).

Р е ш е н и е. Функция элементарная, следовательно, непрерывная на всей области определения.

\(x = 1\) и \(x = - 1\) — точки разрыва. Определим их вид, вычислив пределы:

\(\mathop {\lim }\limits_{x \to 1 + 0} \frac{x}{{{x^2} - 1}} = + \infty \); \(\mathop {\lim }\limits_{x \to 1 - 0} \frac{x}{{{x^2} - 1}} = - \infty \),

\(\mathop {\lim }\limits_{x \to - 1 + 0} \frac{x}{{{x^2} - 1}} = + \infty \); \(\mathop {\lim }\limits_{x \to - 1 - 0} \frac{x}{{{x^2} - 1}} = - \infty \).

Значит, точки \(x = 1\) и \(x = - 1\) — точки разрыва второго рода, а прямые \(x = 1\) и \(x = - 1\) являются вертикальными асимптотами.

Найдем параметры \(k\) и \(b\) наклонной асимптоты:

\(k = \mathop {\lim }\limits_{x \to \pm \infty } \frac{x}{{x\left( {{x^2} - 1} \right)}} = \)\(\mathop {\lim }\limits_{x \to \pm \infty } \frac{1}{{{x^2} - 1}} = 0\),

\(b = \mathop {\lim }\limits_{x \to \pm \infty } \left[ {\frac{x}{{{x^2} - 1}} - 0 \cdot x} \right] = \)\(\mathop {\lim }\limits_{x \to \pm \infty } \frac{x}{{{x^2} - 1}} = 0\),

тогда прямая \(y = 0\) — горизонтальная асимптота.

### Пример 4

Найти наклонные и вертикальные асимптоты функции \(y=x{{e}^{x}}\).

Область определения функции \(\left( -\infty ;+\infty \right)\). Функция элементарная, следовательно, непрерывная на всей области определения. Точек разрыва нет, значит, нет вертикальных асимптот.

Уравнение наклонной асимптоты будем искать в виде \(y=kx+b\).

\( k=\lim\limits_{x\to \infty}\frac{y}{x}= \lim\limits_{x\to \infty}\frac{x{{e}^{x}}}{x}= \lim\limits_{x\to \infty}{{e}^{x}} \).

Заметим, что значение предела зависит от знака бесконечности. Поэтому рассмотрим отдельно:

\( {{k}_{+}}= \lim\limits_{x\to +\infty}\frac{y}{x}= \lim\limits_{x\to +\infty}{{e}^{x}}=+\infty \).

Значит, при \(x\to +\infty \) наклонной асимптоты нет.

\( {{k}_{-}}= \lim\limits_{x\to -\infty}\frac{y}{x}= \lim\limits_{x\to -\infty}{{e}^{x}}=0 \).

Вычислим соответствующее значение \(b\):

\( {{b}_{-}}= \lim\limits_{x\to -\infty}\left( y-0\cdot x \right)= \lim\limits_{x\to -\infty} x{{e}^{x}}=\left[ \infty \cdot 0 \right]= \lim\limits_{x\to -\infty}\frac{x}{{{e}^{-x}}}=\left[ \frac{\infty }{\infty } \right]= \lim\limits_{x\to -\infty}\frac{{{\left( x \right)}^{\prime }}}{{{\left( {{e}^{-x}} \right)}^{\prime }}}= \lim\limits_{x\to -\infty}\frac{1}{-{{e}^{-x}}}=0 \).

Значит, уравнение асимптоты \(y=0\).

Вывод: при \(x\to +\infty \) наклонной асимптоты нет, при \(x\to -\infty \) график функции имеет горизонтальную асимптоту \(y=0\).
