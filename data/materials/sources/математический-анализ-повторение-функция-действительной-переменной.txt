Пусть каждом элементу $x$ множества $D \subset \mathbb{R}$ поставлен в соответствие по определенному закону элемент $y=f(x)$ множества $E \subset \mathbb{R}$, тогда говорят, что на множестве $D$ действует функция $f$ со значениями во множестве $E$. Обозначают $f\;:\;D\rightarrow E$.

Множество $D$ является областью определения функции $f$. Если при этом для каждого элемента $y$ множества $E$ найдется элемент $x$ множества $D$, такой что $y=f(x)$, то множество $E$ называется областью значений функции $f$.

Если каждому элементу $x$ области определения $D$ соответствует единственный элемент $y$ множества значений $E$, то функция является однозначной. Если каким-нибудь элементам области определения соответствуют несколько элементов множества значений, то функция называется многозначной.

Если функция ставит в соответствие каждому элементу множества $D$ единственный элемент множества $E$, и для каждого элемента $y$ множества $E$ найдется единственный элемент $x$ множества $D$, такой что $y=f(x)$, то говорят, что функция $f$ определяет взаимооднозначное соответствие между множествами $D$ и $E$.

Графиком функции $y=f(x)$ в декартовой прямоугольной системе координат является геометрическое место точек $(x;y$), для каждой из которых ордината есть значение $y$ этой функции, соответствующее абсциссе $x$, то есть $(x;y)=(x;f(x))$.

![Иллюстрация](https://minio.k8s.edu.nstu.ru/dicourse-prod/8a52980d-829b-4cfa-af86-b8a0842f3d81.png)

### Виды функций

• основные элементарные функции:
• степенная $y=x^{\alpha}$ ($y=x;\;y=kx+b$ - линейная; $y=x^2;\;y=ax^2+bx+c$ - квадратичная)
• показательная $y=a^x$
• логарифмическая $y=\log_a{x}$
• тригонометрические $y=\cos x,\;y=\sin x,\;y=\operatorname{tg}\;x,\; y=\operatorname{ctg}\;x$
• обратные тригонометрические $y=\operatorname{arccos}\, x,\;y=\arcsin x,\;y=\operatorname{arctg}\;x,\;y=\operatorname{arcctg}\;x$
• элементарные, полученные из основных с помощью конечного числа арифметических операций и композиций; при этом если функция $f(x)$ определена на множестве $D(f)$ со множеством значений $E(f)$, а функция $g(x)$ определена на множестве $D(g)$, то
• сумма функций $f(x)$ и $g(x)$ есть функция $u(x)=f(x)+g(x)$, определенная на пересечении множеств $D(f)$ и $D(g)$;
• произведение функций $f(x)$ и $g(x)$ есть функция $u(x)=f(x)\cdot g(x)$, определенная на пересечении множеств $D(f)$ и $D(g)$;
• частное функций $f(x)$ и $g(x)$ есть функция $u(x)=\frac{f(x)}{g(x)}$, определенная на пересечении множеств $D(f)$ и $D(g)$ для всех $x$ при которых $g(x)\ne 0$;
• композиция функций $f(x)$ и $g(x)$ есть функция $u(x)=g(f(x))$, если $D(g)\subseteq E(f)$ (область определения функции $g(x)$ является подмножеством множества значений функции $f(x)$ или совпадает с ней).
• неэлементарные, заданные с помощью систем из элементарных функций или в виде суммы бесконечного числа элементарных функций.

### Основные свойства функций

Пусть функция $f(x)$ определена на множестве $D\left(f\right)\subset\mathbb{R}$ и $X$ - некоторое подмножество $D$. Вспомним основные свойства, которыми обладают функции действительной переменной.

#### Ограниченность

Функция $f(x)$ называется ограниченной сверху (снизу) на множестве $X\subset{\mathbb R}$, если существует число $M\in{\mathbb R}$, такое, что для всех $x\in X$ выполняется условие

$f(x)\leq M$ $\left(\;f(x)\geq M\;\right)$.

Функция называется ограниченной на множестве, если она ограничена и сверху и снизу на этом множестве.

#### Монотонность

Функция называется возрастающей на множестве $X$, если для любых значений $x_1,x_2 \in X$ из неравенства $x_1 < x_2$ следует $f\left( {x_1 } \right) < f\left( {x_2 } \right)$ (знак неравенства $x_1 < x_2$ сохраняется).

Функция называется убывающей на некотором промежутке $X\subset D\left(f\right)$, если для любых значений $x_1,x_2 \in X$ из неравенства $x_1 < x_2$ следует $f\left( {x_1 } \right) > f\left( {x_2 } \right)$ (знак неравенства $x_1 < x_2$ меняется на противоположный).

Возрастающая (убывающая) на промежутке функция называется строго монотонной на этом промежутке. Чтобы подчеркнуть характер монотонности, про возрастающие и убывающие функции часто говорят "монотонно возрастающая" и "монотонно убывающая".

Иногда используют понятия нестрогой монотонности:

Если для любых $x_1,\;x_2\in X$ из неравенства $x_1 < x_2$ следует $f\left( {x_1 } \right) \leq f\left( {x_2 } \right)$, то функция называется неубывающей.

Если для любых $x_1,\;x_2\in X$ из неравенства $x_1 < x_2$ следует $f\left( {x_1 } \right) \geq f\left( {x_2 } \right)$, то функция называется невозрастающей.

#### Четность

Функция $f(x)$, определенная в симметричном интервале $(-l;l)\subset D$ называется четной, если $f(-x)=f(x)$, и нечетной, если $f(-x)=-f(x)$.
Замечание. Графики четных функций симметричны относительно оси ординат, а графики нечетных функций симметричны относительно начала координат.

#### Периодичность

Функция $f(x)$, определенная в $D$, называется периодической, если существует число $T\ne 0$ такое, что $\forall x\in D$ выполняется $x\pm T\in D$ и $f(x\pm T)=f(x)$. Число $T$ называется периодом функции.

Обычно, говоря о периоде, указывают наименьший положительный (основной) период функции $f(x)$, если он существует. Тогда $kT$ $(k=\pm1,\pm2,\ldots)$ – период функции в широком смысле слова.

Константа является периодической функцией, не имеющей наименьшего положительного периода.

Теорема. Если функция $f\left(x\right)$, определенная в $D_{1\,}$, имеет период $T_{1\,}$, а функция $g\left(x\right)$, определенная в $D_{2\,}$, – период $T_{2\,}$, то функция $f\left(x\right)\pm g\left(x\right)$, определенная в $D=D_1 \cap D_2$ будет периодической только в случае, если отношение $\frac{{T_1}}{{T_2}}$ – рациональное число; при этом ее период $T$ – наименьшее общее кратное чисел $T_{1\,}$ и $T_{2\,}$.

### Линейная функция

Частным случаем степенной функции $y=x^a$ при $a=1$ является линейная функция.

В общем случае линейная функция задается уравнением $y = kx + b$.

Функция определена на всей числовой оси: $D(y)={\mathbb R}$, и ее множество значений – все действительные числа: $E(y)={\mathbb R}$.

Множитель $k$ называется угловым коэффициентом, он равен тангенсу угла наклона прямой к положительному направлению оси абсцисс, слагаемое $b$ называется свободным членом.

При $b = 0$ линейная функция принимает вид $y = kx$ и называется прямой пропорциональностью. Графиком $y = kx$ является прямая, проходящая через начало координат. #### Уравнение прямой в отрезках

Преобразуем выражение $y = kx + b$, для этого перенесем $kx$ влево и разделим обе части уравнения на $b$:

$- \frac{k}{b}x + \frac{y}{b} = 1$.

Обозначим $- \frac{b}{k} = a$, получим равенство

$\frac{x}{a} + \frac{y}{b} = 1$,

которое называют уравнением прямой в отрезках.

Этому уравнению удовлетворяют точки: $\left( {a;0} \right)$ и $\left( {0;b} \right)$, это точки пересечения прямой с координатными осями, при этом говорят, что прямая $\frac{x}{a} + \frac{y}{b} = 1$ отсекает на координатных осях отрезки $a$ и $b$.

#### Уравнение прямой, проходящей через две точки

Так как через любые две точки проходит только одна прямая, то по двум точкам $A\left( {{x_a};{y_a}} \right)$ и $B\left( {{x_b};{y_b}} \right)$ можно однозначно определить уравнение прямой, проходящей через эти точки:

$\frac{{y - {y_a}}}{{{y_b} - {y_a}}} = \frac{{x - {x_a}}}{{{x_b} - {x_a}}}$.

Обратите внимание на частные случаи:

При нахождении уравнений прямых, параллельных координатным осям, с использованием предложенной формулы получаются равенства с 0 в знаменателе. Эти равенства преобразовываются формальным умножением на 0 обеих частей.

Так для прямой, проходящей через точки $A\left( {{x}_{a}};{{y}_{a}} \right)$ и $B\left( {{x}_{b}};{{y}_{a}} \right)$,

$\frac{x-{{x}_{a}}}{{{x}_{b}}-{{x}_{a}}}=\frac{y-{{y}_{a}}}{0}\ \ \Rightarrow \ \ y-{{y}_{a}}=0\ \ \Rightarrow \ \ y={{y}_{a}}$

Эта прямая параллельна оси $Ox$.

### Тригонометрические функции

Единичная окружность с центром в начале координат $O(0;0)$ и центральным углом $\alpha$ называется тригонометрическим кругом.

![Иллюстрация](https://minio.k8s.edu.nstu.ru/dicourse-prod/7d17fc6b-453f-469b-bdca-6ebd0ded82b5.png)

Синусом угла $\alpha$ называется отношение противолежащего катета к гипотенузе в прямоугольном треугольнике $OCP$:

$\sin\alpha=\frac{PC}{OP}=\frac{y}{1}=y$

косинусом угла $\alpha$ называется отношение прилежащего катета к гипотенузе:

$\cos\alpha=\frac{CO}{OP}=\frac{x}{1}=x$

тангенсом называется отношение синуса к косинусу:

$\operatorname {tg} \alpha=\frac{\sin\alpha}{\cos\alpha}$

котангенсом называется отношение косинуса к синусу:

$\operatorname {ctg} \alpha=\frac{\cos\alpha}{\sin\alpha}$

Значения $\cos\alpha$ лежат на оси абсцисс (ось косинусов), значения $\sin \alpha$ лежат на оси ординат (ось синусов), значения $\operatorname{tg}\alpha$ лежат на прямой $x=1$ (ось тангенсов) и значения $\operatorname{ctg}\alpha$ лежат на прямой $y=1$ (ось котангенсов).

Определяя значения $x$, как радианную меру центрального угла тригонометрической окружности $\alpha$, определяют тригонометрические функции:

$y=\sin x$, $y=\cos x$, $y=\operatorname{tg}x$, $y=\operatorname{ctg}x$.

Интервалы знакопостоянства: $\cos x > 0$ при $x \in \left( { - \frac{\pi }{2} + 2\pi k;\frac{\pi }{2} + 2\pi k} \right)$,

$\cos x < 0$ при $x \in \left( {\frac{\pi }{2} + 2\pi k;\frac{{3\pi }}{2} + 2\pi k} \right)$, $k \in {\mathbb{Z}}$.

Интервалы монотонности: функция возрастает на интервалах $x \in \left( { - \pi + 2\pi k;2\pi k} \right)$ и убывает на интервалах $x \in \left( {2\pi k;\pi + 2\pi k} \right)$, $k \in {\mathbb{Z}}$.

Функция $y=\cos x$ ограниченная: $- 1 \le \cos x \le 1$.

#### Тригонометрические тождества

Формулы приведения:

$\sin(a\pm \pi)=-\sin a$; $\sin\left(a+\frac\pi2\right)=\cos a$; $\sin\left(a-\frac\pi2\right)=-\cos a$

$\cos(a\pm \pi)=-\cos a$; $\cos\left(a+\frac\pi2\right)=-\sin a$; $\cos\left(a-\frac\pi2\right)=\sin a$

Основное тригонометрическое тождество: $\cos^2x+\sin^2x=1$

Формулы двойных углов:

$\cos 2x=\cos^2x-\sin^2x$; $\sin2x=2\sin x\cos x$

Формулы понижения степени:

$\cos^2x=\frac{1+\cos 2x}{2}$; $\sin^2x=\frac{1-\cos2x}{2}$

Формулы суммы и разности аргументов:

$\sin(a\pm b)=\sin a\cos b\pm \sin b \cos a$; $\cos(a\pm b)=\cos a\cos b\mp\sin a\sin b$

Формулы произведения функций:

$\sin a\sin b=\frac12\left(\cos(a-b)-\cos(a+b)\right)$;

$\cos a\cos b=\frac12\left(\cos(a-b)+\cos(a+b)\right)$;

$\sin a\cos b=\frac12\left(\sin(a-b)+\sin(a+b)\right)$

### Тригонометрические функции (tg x и ctg x)

#### Тангенс

Формула: $y=\operatorname{tg} x$

Область определения: $D(y)=\mathbb{R}\setminus\left\{ \frac\pi2+\pi k, \;k\in\mathbb{Z}\right\}$

Множество значений: $E(y)=\mathbb{R}$

![Иллюстрация](https://minio.k8s.edu.nstu.ru/dicourse-prod/6359f454-cc8b-443e-9495-8f5404a2c860.png)

Функция нечетная, так как ${\mathop{\rm tg}\nolimits} \left( { - x} \right) = - {\mathop{\rm tg}\nolimits} x$ . График функции симметричен относительно начала координат.

Функция периодическая; основной период $T = \pi$: $\operatorname{tg}\left(x+\pi k\right)=\operatorname{tg}x;\;k\in\mathbb{Z}$

Нули функции: ${\mathop{\rm tg}\nolimits} x = 0 \Rightarrow \frac{{\sin x}}{{\cos x}} = 0 \Leftrightarrow \sin x = 0 \Leftrightarrow x = \pi k,\;\;k \in {\mathbb{Z}}$.

Интервалы знакопостоянства: $\operatorname{tg} x < 0$ при $x \in \left( { - \frac{\pi }{2} + \pi k;\pi k} \right)$, $\operatorname{tg} x > 0$ при $x \in \left( {\pi k;\frac{\pi }{2} + \pi k} \right)$, $k \in {\bf{Z}}$.

Функция возрастает на интервалах $\left( { - \frac{\pi }{2} + \pi k;\frac{\pi }{2} + \pi k} \right)$, $k \in {\mathbb{Z}}$ (на всей области определения)

Функция неограниченная.

#### Котангенс

Формула: $y=\operatorname{ctg} x$

Область определения: $D(y)=\mathbb{R}\setminus\left\{\pi k, \;k\in\mathbb{Z}\right\}$

Множество значений: $E(y)=\mathbb{R}$

![Иллюстрация](https://minio.k8s.edu.nstu.ru/dicourse-prod/2fe54f8a-e210-490a-9ce5-effd9e9df8a7.png)

Функция нечетная, так как ${\mathop{\rm ctg}\nolimits} \left( { - x} \right) = - {\mathop{\rm ctg}\nolimits} x$ . График функции симметричен относительно начала координат.

Функция периодическая; основной период $T = \pi$.

Нули функции: ${\mathop{\rm ctg}\nolimits} x = 0 \Rightarrow \frac{{\cos x}}{{\sin x}} = 0 \Leftrightarrow \cos x = 0 \Leftrightarrow x = \frac{\pi }{2} + \pi k,\;\;k \in {\bf{Z}}$.

Интервалы знакопостоянства: $\operatorname{ctg} x < 0$ при $x \in \left( {\pi k;\frac{\pi }{2} + \pi k} \right)$, $\operatorname{ctg} x > 0$ при $x \in \left( {\frac{\pi }{2} + \pi k;\pi + \pi k} \right)$, $k \in {\bf{Z}}$.

Функция убывает на интервалах $\left( {\pi k;\pi + \pi k} \right)$, $k \in {\bf{Z}}$ (на всей области определения).

Функция неограниченная.

#### Тригонометрические тождества*

Формулы приведения

$\operatorname{tg} \left(x\pm\pi\right)=\operatorname{tg} x$; $\operatorname{tg} \left(x\pm\frac\pi2\right)=-\operatorname{ctg} x$

$\operatorname{ctg} \left(x\pm\pi\right)=\operatorname{ctg} x$; $\operatorname{ctg} \left(x\pm\frac\pi2\right)=-\operatorname{tg} x$

Следствие основного тригонометрического тождества

$1+\operatorname{tg}^2x=\frac1{\cos^2x}$; $1+\operatorname{ctg}^2x=\frac1{\sin^2 x}$

Формулы двойных аргументов

$\operatorname{tg} 2x=\frac{2\operatorname{tg} x}{1-\operatorname{tg}^2x }$

$\operatorname{ctg} 2x=\frac{\operatorname{ctg}^2x-1 }{2\operatorname{ctg} x}$

Формулы суммы аргументов

$\operatorname{tg} (a\pm b)=\frac{\operatorname{tg} a\pm \operatorname{tg} b}{1\mp \operatorname{tg} a\operatorname{tg} b}$

$\operatorname{ctg} (a\pm b)=\frac{\operatorname{ctg} a\operatorname{ctg} b\mp 1}{\operatorname{ctg} a\pm \operatorname{ctg} b}$

Формулы выражения тригонометрических функций через тангенс половинного аргумента

$\sin x=\frac{2\operatorname{tg}\frac{x}2}{1-\operatorname{tg}^2\frac{x}2}$

$\cos x=\frac{1-\operatorname{tg}^2\frac{x}2}{1+\operatorname{tg}^2\frac{x}2}$

$\operatorname{tg}x=\frac{2\operatorname{tg}\frac{x}2}{1-\operatorname{tg}^2\frac{x}2}$

*приведенные формулы верны в соответствующих областях допустимых значений аргументов!

### Обратные тригонометрические функции

Функции, обратные функциям $y = \sin x$, $y = \cos x$, $y = {\mathop{\rm tg}\nolimits} x$ и $y = {\mathop{\rm ctg}\nolimits} x$ на соответствующих интервалах называются обратными тригонометрическими функциями.

Тригонометрические функции $y = \sin x$ и $y = \cos x$ не являются монотонными на всей области определения, поэтому для построения обратных тригонометрических функций выделяют интервалы монотонности.

#### Арксинус

Функция $y = \sin x$ возрастает на отрезке $\left[ { - \frac{\pi }{2};\frac{\pi }{2}} \right]$ и принимает все значения от -1 до 1. Значит, для функции $y = \sin x$ при $- \frac{\pi }{2} \le x \le \frac{\pi }{2}$ существует обратная функция. Эту функцию обозначают $y = \arcsin x$.

Область определения функции: $D\left( y \right) = \left[ { - 1;1} \right]$ или $- 1 \le x \le 1$.

Множество значений функции: $E\left( y \right) \in \left[ { - \frac{\pi }{2};\frac{\pi }{2}} \right]$ или $- \frac{\pi }{2} \le y \le \frac{\pi }{2}$.

Функция нечетная, так как $\arcsin \left( { - x} \right) = - \arcsin x$.

Нуль функции: $y = 0$ при $x = 0$.

Интервалы знакопостоянства:

$\arcsin x < 0$ при $x \in \left[ { - 1;0} \right)$; $\arcsin x > 0$ при $x \in \left( {0;1} \right]$.

Функция возрастает на всей области определения.

Функция непериодическая.

$\sin \left( {\arcsin x} \right) = x$ при $x \in \left[ { - 1;1} \right]$.

График функции

При рассмотрении обратной функции $y = \arcsin x$ на отрезке $\left[ { - \frac{\pi }{2};\frac{\pi }{2}} \right]$ значение $y$ называют главным значением и обозначают $\arcsin x$. Другие значения $y = {\mathop{\rm Arcsin}\nolimits} x$ выражаются через его главное значение формулой:

${\mathop{\rm Arcsin}\nolimits} x = \arcsin x + 2\pi k,\;\;k \in {\bf{Z}}$.

#### Арккосинус

Функция $y = \cos x$ убывает на отрезке $\left[ {0;\pi } \right]$ и принимает все значения от -1 до 1. Значит, для функции $y = \cos x$ при $0 \le x \le \pi$ существует обратная функция. Эту функцию обозначают $y = \arccos x$.

Область определения функции: $D\left( y \right) = \left[ { - 1;1} \right]$ или $- 1 \le x \le 1$.

Множество значений функции: $E\left( y \right) \in \left[ {0;\pi } \right]$ или $0 \le y \le \pi$.

Функция общего вида: $\arccos \left( { - x} \right) = \pi - \arccos x$.

Нуль функции: $y = 0$ при $x = 1$.

Интервалы знакопостоянства:

$\arccos x > 0$ при $x \in \left[ { - 1;1} \right)$.

Функция убывает на всей области определения.

Функция непериодическая.

$\cos \left( {\arccos x} \right) = x$ при $x \in \left[ { - 1;1} \right]$.
