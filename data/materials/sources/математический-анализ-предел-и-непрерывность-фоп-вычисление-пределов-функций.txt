### Вычисление пределов функции

Для вычисления пределов функций, прежде всего, нужно подставить предельное значение аргумента в функцию под знаком предела и, используя свойства, найти предел.

При подстановке предельных значений могут возникнуть особые ситуации:

$\left[ \infty -\infty \right],\ \ \left[ \frac{\infty }{\infty } \right],\ \ \left[ \frac{0}{0} \right],\ \ \left[ \infty \cdot 0 \right]$,

которые называются неопределенностями. При вычислении пределов неопределенности раскрываются с помощью алгебраических преобразований.

Пример 1. Вычислить $\lim\limits_{x\to 0}\left( \frac{{{x}^{3}}-3x+1}{{{x}^{2}}-4}+1 \right)$.

Р е ш е н и е. Выполним подстановку $x=0$ в функцию под знаком предела:

$\lim\limits_{x\to 0}\left( \frac{{{x}^{3}}-3x+1}{{{x}^{2}}-4}+1 \right)=\frac{1}{-4}+1=\frac{3}{4}$

получили конкретное значение, которое и является значением предела функции в точке $x=0$.

Пример 2. Вычислить $\lim\limits_{x\to 1}\frac{x}{1-x}$.

Р е ш е н и е. Подставим $x= 1$ в числитель и знаменатель дроби:

$\lim\limits_{x\to 1}\frac{x}{1-x}=\left[\frac{1}{0}\right]=\infty$

!!! Не путайте с действием деления на 0, которое не существует. В данном случае 0 использован, как обозначение бесконечно малой функции.

При решении задач ответ $\infty$ записывайте буквой "б" (без кавычек!), ответ $+\infty$ как "+б", ответ $-\infty$ как "-б".

### Предел функций на ∞

При вычислении пределов при $x \to \infty$ необходимо помнить о множествах значений основных элементарных функций и представлять значения этих функций при достаточно больших по абсолютной величине значениях аргумента, так:

$\mathop {\lim }\limits_{x \to \infty } {x^2} = + \infty$, $\mathop {\lim }\limits_{x \to \infty } {x^3} = \infty$, $\lim\limits_{x\to\infty}\frac1{x^2}=\left[\frac1\infty\right]=0$.

Полезно помнить, что для бесконечно больших значений аргумента имеет место шкала роста функций

$\underbrace {\ln ^a x}_{\forall a} < \underbrace {x^b }_{\forall b>0} < \underbrace {a^x }_{\forall a > 1}$,

для элементов которой по-прежнему работает правило

$\lim\limits_{n \to \infty }\frac{m}{b}= 0$,

где $m$ – меньший элемент, $b$ – больший элемент.

Для многочленов вещественного аргумента для его бесконечно больших значений имеет место та же эквивалентность, что и для последовательностей:

$P_k(x)=a_0x^k+a_1x^{k-1}+\ldots+a_n\sim a_0x^k$ при $x\to\infty$.

Если при вычислении пределов последовательностей натуральный аргумент может принимать только положительные значения, то вещественный аргумент может быть как положительным бесконечно большим, так и отрицательным. Иногда в задаче важен знак бесконечно большой величины:

$\mathop {\lim }\limits_{x \to - \infty } {x^3} = - \infty$ и $\mathop {\lim }\limits_{x \to + \infty } {x^3} = + \infty$.

Иногда знак существенно важен:

так $\mathop {\lim }\limits_{x \to + \infty } \ln x = + \infty$, но $\mathop {\lim }\limits_{x \to - \infty } \ln x$ не существует, так как область определения логарифма – множество положительных чисел.

Важен знак аргумента и для показательной функции:

$\mathop {\lim }\limits_{x \to + \infty } {e^x} = \left[e^{+ \infty }\right]=+ \infty$, но

$\mathop {\lim }\limits_{x \to - \infty } {e^x} =\left[e ^{-\infty}=\frac{1}{e^{+\infty}}=\frac{1}{+ \infty }\right] =0$.

Для обратных тригонометрических функций следует помнить, что

$\mathop {\lim }\limits_{x \to + \infty } {\mathop{\rm arctg}\nolimits} x = \frac{\pi }{2}$, а $\mathop {\lim }\limits_{x \to - \infty } {\mathop{\rm arctg}\nolimits} x = - \frac{\pi }{2}$.

$\mathop {\lim }\limits_{x \to + \infty } {\mathop{\rm arcctg}\nolimits} x = 0$, а $\mathop {\lim }\limits_{x \to - \infty } {\mathop{\rm arcctg}\nolimits} x = \pi$.

Запомните, что $\mathop {\lim }\limits_{x \to \infty } \sin x$ и $\mathop {\lim }\limits_{x \to \infty } \cos x$ не существуют, так как синус и косинус периодические функции, принимающие при бесконечном возрастании аргумента любые значения из промежутка $\left[ { - 1;1} \right]$.

Также не существуют пределы $\mathop {\lim }\limits_{x \to \infty } {\mathop{\rm tg}\nolimits} x$ и $\mathop {\lim }\limits_{x \to \infty } {\mathop{\rm ctg}\nolimits} x$.
