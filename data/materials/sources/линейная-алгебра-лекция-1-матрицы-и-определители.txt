Лекция 1. Матрицы и определители

Матрицей размера m×n называется прямоугольная таблица чисел, содержащая m строк и n столбцов. Элемент матрицы, стоящий в i-й строке и j-м столбце, обозначается a_ij. Матрица, у которой число строк равно числу столбцов, называется квадратной, а её размер называют порядком. Диагональ, идущая из левого верхнего угла в правый нижний, называется главной, другая диагональ называется побочной.

Основные операции над матрицами. Сложение определено только для матриц одинакового размера и выполняется поэлементно. Умножение на число k выполняется умножением каждого элемента на это число. Произведение матриц A и B определено, когда число столбцов A равно числу строк B; элемент произведения с индексами i,j равен сумме произведений элементов i-й строки A на соответствующие элементы j-го столбца B. Произведение матриц, вообще говоря, не коммутативно: AB не равно BA.

Транспонированием называется операция замены строк матрицы её столбцами. Матрица, совпадающая со своей транспонированной, называется симметрической. Единичной матрицей E называется квадратная матрица, у которой на главной диагонали стоят единицы, а все остальные элементы равны нулю. Для любой квадратной матрицы A выполняется AE = EA = A. Матрица, определитель которой равен нулю, называется вырожденной; обратная матрица существует только для невырожденных матриц.

Определителем квадратной матрицы второго порядка называется число, равное разности произведения элементов главной диагонали и произведения элементов побочной диагонали: det [[a, b], [c, d]] = ad - bc. Например, определитель матрицы [[5, 2], [1, 3]] равен 5·3 - 2·1 = 15 - 2 = 13.

Для определителя третьего порядка используется правило треугольника либо разложение по строке или столбцу. Минором M_ij элемента a_ij называется определитель матрицы, полученной вычёркиванием i-й строки и j-го столбца. Алгебраическим дополнением A_ij называется величина A_ij = (-1)^(i+j) · M_ij. Тогда определитель равен сумме произведений элементов любой строки на их алгебраические дополнения: det A = a_i1·A_i1 + a_i2·A_i2 + ... + a_in·A_in. Это разложение справедливо по любой строке и любому столбцу, что позволяет выбирать линию с наибольшим числом нулей.

Свойства определителей. При транспонировании определитель не меняется. При перестановке двух строк знак определителя меняется на противоположный. Если строка состоит из нулей, определитель равен нулю. Если две строки пропорциональны, определитель равен нулю. Общий множитель строки можно вынести за знак определителя. Если к одной строке прибавить другую, умноженную на число, определитель не изменится. Определитель произведения матриц равен произведению определителей: det(AB) = det A · det B.

Обратная матрица. Матрица A^(-1) называется обратной к A, если A·A^(-1) = A^(-1)·A = E. Для невырожденной матрицы обратная матрица существует и единственна. Она вычисляется по формуле A^(-1) = (1/det A) · adj(A), где adj(A) — присоединённая матрица, составленная из алгебраических дополнений и затем транспонированная. Для матрицы второго порядка [[a, b], [c, d]] обратная равна (1/(ad - bc)) · [[d, -b], [-c, a]].

Метод Крамера применяется к системам n линейных уравнений с n неизвестными, если определитель основной матрицы отличен от нуля. Решение находится по формулам x_i = det A_i / det A, где A_i получается заменой i-го столбца матрицы системы на столбец свободных членов. Например, для системы 2x + y = 5, x + 3y = 10: определитель системы равен 2·3 - 1·1 = 5, определитель по x равен 5·3 - 1·10 = 5, откуда x = 1; определитель по y равен 2·10 - 5·1 = 15, откуда y = 3.

Метод Гаусса состоит в приведении расширенной матрицы системы к ступенчатому виду элементарными преобразованиями строк: перестановкой строк, умножением строки на ненулевое число и прибавлением к строке другой строки, умноженной на число. Обратный ход метода Гаусса позволяет последовательно найти все неизвестные. Если в ступенчатом виде появляется строка вида 0 = b при b ≠ 0, система несовместна. Если число ненулевых строк меньше числа неизвестных, система имеет бесконечно много решений и переменные делятся на базисные и свободные.

Рангом матрицы называется максимальное число линейно независимых строк. Ранг не меняется при элементарных преобразованиях строк. Система линейных уравнений совместна тогда и только тогда, когда ранг расширенной матрицы равен рангу основной матрицы (теорема Кронекера — Капелли). Если этот ранг равен числу неизвестных, решение единственно; если меньше, решений бесконечно много.

Типовые ошибки при решении. Потеря знака при вычислении алгебраического дополнения, поскольку множитель (-1)^(i+j) зависит от суммы индексов. Неверное транспонирование присоединённой матрицы при построении обратной. Применение формул Крамера при нулевом определителе системы. Арифметические ошибки при делении на определитель. Проверка ответа выполняется подстановкой найденных значений в исходную систему, а для обратной матрицы — умножением A на A^(-1) с проверкой получения единичной матрицы.
