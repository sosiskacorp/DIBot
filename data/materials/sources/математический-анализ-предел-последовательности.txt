Определение. Функция $f:{\bf{N}} \to {\bf{R}}$ называется последовательностью, значения функции

$a_n= f\left( n \right)$, где $n \in {\bf{N}}$

называются членами последовательности.

Последовательность обозначают $\left\{ {a_n } \right\}_{n = 1}^\infty$.

Определяя формулу общего члена, можно вычислить любой член последовательности:

$\left\{\frac1n\right\}_{n=1}^{\infty}$, то есть $a_n=\frac1n$ и $a_1=\frac11,\;a_2=\frac12,\;a_3=\frac13,\ldots$;

$\left\{(-1)^n\right\}_{n=1}^{\infty}$, то есть $a_n=(-1)^n$ и $a_1=-1,\;a_2=1,\;a_3=-1,\ldots$.

Определение. Последовательность $\left\{ {x_n } \right\}_{n = 1}^\infty$ называется бесконечно большой, если для любого сколь угодно большого числа $E$ найдется номер $n_0$, такой, что для всех элементов последовательности с номерами большими $n_0$ выполнено неравенство

$\left| {x_n } \right| > E$.

Или кратко:

$\forall \;E > 0\;\exists \;n_0(E)\;:\;\forall \;n > n_0 \Rightarrow \left| {x_n } \right| > E$.

Пример 1. Покажем, что последовательность $\left\{ {q^n } \right\}_{n = 1}^\infty$ является бесконечно большой, если $\left| q \right| > 1$.

По определению

$\forall \;E > 0\;\exists \;n_0(E)\;:\;\forall \;n > n_0 \Rightarrow \left| {q^n } \right| > E$,

укажем такой номер $n_0\left( E \right)$.

Разрешим неравенство $\left| {q^n } \right| > E$ относительно $n$:

$\left| {q^n } \right| =\left|q\right|^n\;\Rightarrow\; \left|q\right|^n>E\;\Leftrightarrow\;n>\log_{|q|}E$

(так как основание $q>1$ то при логарифмировании знак неравенства сохраняется).

Взяв в качестве $n_0$ целую часть $\log_{|q|}E$ (так как $n_0$ - натуральное число), получим, что для всех $n>n_0=\left[\log_{|q|}E\right]$ выполняется неравенство $\left| {q^n } \right| > E$ , значит действительно, последовательность $\left\{ {q^n } \right\}_{n = 1}^\infty$ при $\left| q \right| > 1$ бесконечно большая.

Без доказательства принимаем, что последовательности, общий член которых стремится к бесконечно большим значениям с ростом их номеров, являются бесконечно большими, например, $\left\{n^2\right\}_{n = 1}^\infty$, $\left\{ \sqrt{n} \right\}_{n = 1}^\infty$, $\left\{ n!\right\}_{n = 1}^\infty$ - бесконечно большие последовательности.

### Ограниченная последовательность

Определение. Последовательность называется ограниченной, если найдется число $C \in {\bf{R}}$, такое что для всех членов последовательности выполняется неравенство

$\left| {a_n } \right| \leq C$.

Если такого числа подобрать нельзя, то последовательность называется неограниченной.

Теорема (о неограниченности бесконечно большой последовательности). Всякая бесконечно большая последовательность является неограниченной.

Доказательство. Построим отрицание определения ограниченной последовательности (квантор $\forall$ заменим на $\exists$ и наоборот): последовательность $\left\{{a_n}\right\}_{n =1}^\infty$ является неограниченной, если

$\forall \;E > 0\;\exists \;n_0\;:\;\left| {a_{n_0}} \right|>E$,

последнее неравенство выполняется для бесконечного числа элементов бесконечно большой последовательности, таким образом, бесконечно большая последовательность является неограниченной. Теорема доказана.

Обратное, вообще говоря, неверно, из неограниченности последовательности не следует то, что она является бесконечно большой. Так последовательность $\left\{ {1,\;2,\;1,\;3,\;1 \ldots ,\;1,\;n,\;1,\;n + 1,\; \ldots } \right\}$ является неограниченной, так как для любого сколь угодно большого числа найдется больший элемент последовательности, но не является бесконечно большой, так как для произвольного числа $E$ не все элементы, начиная с некоторого, будут больше $E$.

Примерами ограниченных последовательностей являются

$\left\{ \sin n \right\}_{n = 1}^\infty$, так как $\left|\sin n\right|\le 1\;\forall \;n\in{\bf N}$,

$\left\{ \frac{n}{n+1} \right\}_{n = 1}^\infty$, так как $0<\frac{n}{n+1}< 1\;\forall \;n\in{\bf N}$.

### Бесконечно малая последовательность

Определение. Последовательность $\left\{{a_n}\right\}_{n=1}^\infty$ называется бесконечно малой, если для любого сколь угодно малого числа $\varepsilon$ найдется номер $n_0\left(\varepsilon\right)$, такой, что для всех элементов последовательности с номерами большими $n_0$ выполнено неравенство $\left|{a_n}\right|<\varepsilon$. Или кратко:

$\forall\;\varepsilon >0\;\exists \;n_0(\varepsilon)\;:\;\forall \;n > n_0\Rightarrow \left|{a_n}\right| < \varepsilon$.

Пример 2. Покажем, что последовательность $\left\{\frac{1}{n}\right\}_{n=1}^\infty$ является бесконечно малой.

По определению имеем

$\forall\;\varepsilon>0\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n >n_0\Rightarrow\left|{\frac{1}{n}} \right| < \varepsilon$,

найдем такой номер $n_0\left(\varepsilon\right)$:

$\frac{1}{n} < \varepsilon$ $\Leftrightarrow$ $n > \varepsilon$,

следовательно, найден номер $n_0=\left[{\frac{1}{\varepsilon}} \right]+1$ (добавили 1 на случай, если окажется, что $\left[{\frac{1}{\varepsilon}}\right]=0$, а 0 не является натуральным числом), начиная с которого все элементы последовательности с номерами большими $n_0$ удовлетворяют неравенству $\left|a_n\right|<\varepsilon$ и, значит, исследуемая последовательность действительно является бесконечно малой.

Пример 3. Последовательность $\left\{ {q^n } \right\}_{n = 1}^\infty$ является бесконечно малой, если $\left| q \right| < 1$.

По определению

$\forall \;\varepsilon> 0\;\exists \;n_0(\varepsilon)\;:\;\forall \;n > n_0 \Rightarrow \left| {q^n } \right| > \varepsilon$,

укажем такой номер $n_0\left( \varepsilon \right)$.

Разрешим неравенство $\left| {q^n } \right| < \varepsilon$ относительно $n$:

$\left| {q^n } \right| =\left|q\right|^n\;\Rightarrow\; \left|q\right|^n<\varepsilon\;\Leftrightarrow\;n>\log_{|q|}\varepsilon$

(так как основание $|q|<1$ то при логарифмировании знак неравенства меняется на противоположный).

Взяв в качестве $n_0$ целую часть $\log_{|q|}\varepsilon$ (так как $n_0$ - натуральное число), получим, что для всех $n>n_0=\left[\log_{|q|}\varepsilon\right]$ выполняется неравенство $\left| {q^n } \right| < \varepsilon$ , значит действительно, последовательность $\left\{ {q^n } \right\}_{n = 1}^\infty$ при $\left| q \right| < 1$ бесконечно малая.

Без доказательства принимаем, что если общий член последовательности при неограниченном возрастании его номера стремится к нулю, то последовательность является бесконечно малой. Так бесконечно малыми являются последовательности $\left\{ \frac1{n^2} \right\}_{n = 1}^\infty$, $\left\{ \frac{1}{\sqrt n} \right\}_{n = 1}^\infty$.

Теорема. Бесконечно малая последовательность является ограниченной.

Доказательство. Пусть $\left\{ {a_n } \right\}_{n = 1}^\infty$ – бесконечно малая последовательность, т.е. по определению

$\forall \;\varepsilon > 0\;\;\exists \;\;n_0 \left( \varepsilon \right)\;:\;\forall \;n > n_0 \Rightarrow \;\left| {a_n } \right| < \varepsilon$,

следовательно, последовательность $\left\{ {a_n } \right\}_{n = n_0 + 1}^\infty$ ограничена.

Так как число элементов последовательности с номерами от 1 до $n_0$ конечно, то среди элементов $a_1 ,\;a_2 ,\; \ldots \;,a_{n_0 }$ можно найти наибольший по абсолютной величине:

$a_m = \max \left\{ {\left|a_1\right| ,\;\left|a_2 \right|,\; \ldots \;,\left|a_{n_0 }\right| } \right\}$.

Таким образом, для $\forall \;n \Rightarrow \;\left| {a_n } \right| < \max \left\{ {\varepsilon ,a_m } \right\}$, что означает, что последовательность $\left\{ {a_n } \right\}_{n = 1}^\infty$ ограничена. Теорема доказана.

### Теорема о связи бесконечно большой и бесконечно малой

Теорема. Последовательность $\left\{{a_n}\right\}_{n=1}^\infty$ является бесконечно большой тогда и только тогда, когда последовательность $\left\{{\frac{1}{{a_n }}}\right\}_{n=1}^\infty$, начиная с некоторого $n$, является бесконечно малой.

Доказательство. Действительно, если последовательность $\left\{{a_n}\right\}_{n=1}^\infty$ - бесконечно большая, то по определению $\forall \;E > 0\;\exists \;n_0(E)\;:\;\forall \;n > n_0 \Rightarrow \left|{a_n}\right| >E$. Поскольку $E$ – произвольное, то возьмем $E =\frac{1}{\varepsilon}$, где $\varepsilon$ положительное сколь угодно малое число, тогда из последнего неравенства следует

$\left| {\frac{1}{{a_n }}}\right| < \frac{1}{E}=\varepsilon$,

или, что последовательность $\left\{{\frac{1}{{a_n}}} \right\}_{n = 1}^\infty$удовлетворяет условию

$\forall \;\varepsilon>0\;\exists\;n_0(\varepsilon)\;:\;\forall \;n > n_0\Rightarrow \left|{\frac{1}{a_n}}\right| < \varepsilon$,

т.е. является бесконечно малой. Теорема доказана.

Пример 4. Последовательность $\left\{{q^n}\right\}_{n=1}^\infty$ является бесконечно большой при $\left| q \right| >1$ и бесконечно малой при $\left| q \right| < 1$.

Неформально утверждение этой теоремы будем записывать так:

$\left[\frac1{\infty}\right]=0$ и $\left[\frac10\right]=\infty$,

где символ $\infty$ означает бесконечно большую, а $0$ - бесконечно малую.

### Теорема об арифметике бесконечно больших и бесконечно малых

Пусть $\{a_n \}_{n=1}^{\infty}$ и $\{b_n \}_{n=1}^{\infty}$ - бесконечно малые, а $\{k_n \}_{n=1}^{\infty}$ ограниченная, тогда

$\{k_n⋅a_n \}_{n=1}^{\infty}, \{a_n\pm b_n \}_{n=1}^{\infty}, \{a_n⋅b_n \}_{n=1}^{\infty}$ - бесконечно малые.

Важно: отношение бесконечно малых может оказаться как бесконечно малой, так и бесконечно большой, или ограниченной.

Например, для бесконечно малых последовательностей $\left\{a_n\right\}=\{\frac1{n^2}\}_{n=1}^{\infty}$ и $\left\{b_n\right\}=\left\{\frac1{n^3}\right\}_{n=1}^{\infty}$ отношение $\left\{\frac{a_n}{b_n}\right\}=\left\{n\right\}_{n=1}^{\infty}$ - бесконечно большая, а $\left\{\frac{b_n}{a_n}\right\}=\left\{\frac1n\right\}_{n=1}^{\infty}$ - бесконечно малая последовательность.

Отношение бесконечно малых символично обозначают $\left[\frac00\right]$ и называют неопределенностью.

Пусть $\{a_n \}_{n=1}^{\infty}$ и $\{b_n \}_{n=1}^{\infty}$ - бесконечно большие, а $\{k_n \}_{n=1}^{\infty}$ ограниченная, тогда

$\{k_n⋅a_n \}_{n=1}^{\infty}$ и $\{a_n⋅b_n \}_{n=1}^{\infty}$ - бесконечно большие.

Важно: сумма/разность и частное бесконечно больших может оказаться как бесконечно малой, так и бесконечно большой, или ограниченной.

Например, для бесконечно больших последовательностей $\left\{a_n\right\}=\{n^2\}_{n=1}^{\infty}$ и $\left\{b_n\right\}=\left\{n^3\right\}_{n=1}^{\infty}$ их разность является бесконечно большой:

$a_n-b_n=n^2-n^3=n^3\left(\frac1n-1\right)$

Последовательность $\left\{\frac1n\right\}$ - бесконечно малая, $\left\{1-\frac1n\right\}$ - ограниченная, следовательно, $\left\{n^3\left(\frac1n-1\right)\right\}$ - бесконечно большая.

Для последовательностей $\{a_n\} =\left\{\sqrt{n^2+1}\right\}_{n=1}^{\infty}$ и $\{b_n\} =\left\{n\right\}_{n=1}^{\infty}$ их разность является бесконечно малой:

$a_n-b_n=\sqrt{n^2+1}-n=\frac{\left(\sqrt{n^2+1}-n\right)\left(\sqrt{n^2+1}+n\right)}{\sqrt{n^2+1}+n}=\frac{n^2+1-n^2}{\sqrt{n^2+1}+n}=\frac{1}{\sqrt{n^2+1}+n}$

$\frac{1}{\sqrt{n^2+1}+n}\to 0$ при $n\to\infty$, следовательно, $\left\{a_n-b_n\right\}_{n=1}^{\infty}$ - бесконечно малая последовательность.

Определение. Пределом последовательности $\left\{{a_n}\right\}_{n=1}^\infty$ называется число $a$, такое, что

$\forall\;\;\varepsilon > 0\;\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n > n_0\;\Rightarrow\;\left| {a_n-a}\right| < \varepsilon$.

Обозначается $a=\lim\limits_{n\to\infty}a_n$. Если $a$ конечно, то последовательность называется сходящейся.

Если такого числа $a$ не существует или $a=\infty$, то последовательность называется расходящейся.

Если $a$ – конечное число, то сходимость последовательности к $a$ означает, что, начиная с некоторого номера, все элементы последовательности лежат в сколь угодно малой окрестности числа $a$.

Пример 5. Покажем, что $\lim\limits_{n\to\infty}\frac{{n + 1}}{n}= 1$.

По определению запишем:

$\forall\;\;\varepsilon > 0\;\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n > n_0\;\Rightarrow\;\left| {\frac{{n + 1}}{n}-1}\right| < \varepsilon$.

Решим последнее неравенство:

$\left| {\frac{{n + 1}}{n}-1}\right| < \varepsilon\;\;\Leftrightarrow\;\;\left| {\frac{{n + 1-n}}{n}}\right| < \varepsilon\;\;\Leftrightarrow\;\;\left| {\frac{1}{n}}\right| < \varepsilon\;\;\Leftrightarrow\;\;n >\frac{1}{\varepsilon}$.

Значит, взяв в качестве номера $n_0=\left[ {\frac{1}{\varepsilon}}\right] + 1$, для всех $n > n_0$ получим выполнение неравенства $\left| {\frac{{n + 1}}{n}-1}\right| < \varepsilon$, следовательно, действительно, $\lim\limits_{n\to\infty}\frac{{n + 1}}{n}= 1$.

Число $a$ может быть как конечным, так и равным бесконечности. Если $\lim\limits_{n\to \infty}=\infty$, то последовательность является бесконечно большой. Если $\lim\limits_{n\to\infty}а_n=0$, то последовательность является бесконечно малой.

Заметим, что неравенство $\left| {x_n-a}\right| < \varepsilon$ в определении сходящейся последовательности означает, что последовательность $\left\{{x_n-a}\right\}_{n=1}^\infty$ является бесконечно малой. Обозначив $\left\{{x_n-a}\right\}_{n=1}^\infty =\left\{{\alpha _n}\right\}_{n=1}^\infty$, получим выражение для элемента сходящейся последовательности

$x_n=a+\alpha_n$,

где $\alpha_n$ - элемент бесконечно малой последовательности.

### Теорема единственности предела последовательности

Лемма. Если все элементы бесконечно малой последовательности $\left\{{\alpha _n}\right\}_{n=1}^\infty$ равны одному и тому же числу $c$, то $c=0$.

Доказательство. Предположим противное, т.е. что $c\neq 0$. Пусть $\varepsilon=\frac{{\left| c\right|}}{2}$, тогда по определению бесконечно малой последовательности

$\forall\;\;\varepsilon > 0\;\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n > n_0\;\Rightarrow\;\left| {\alpha _n}\right| < \varepsilon$.

Так как $\alpha _n=c$ и $\varepsilon=\frac{{\left| c\right|}}{2}$, то последнее неравенство можно переписать в виде

$\left| c\right| < \frac{{\left| c\right|}}{2}$,

откуда $1 < \frac{1}{2}$ – противоречие. Следовательно, утверждение $c\neq 0$ не может иметь места, и, значит, $c=0$.

Теорема (единственности предела последовательности). Сходящаяся последовательность имеет единственный предел.

Доказательство. От противного. Пусть сходящаяся последовательность имеет два предела

$\lim\limits_{n\to\infty}x_n=a$ и $\lim\limits_{n\to\infty}x_n=b$, и $a\neq b$.

Тогда для элементов $x_n$ верны представления:

$x_n=a +\alpha _n$ и $x_n=b +\beta _n$,

где $\alpha _n$ и $\beta _n$ – элементы бесконечно малых последовательностей $\left\{{\alpha _n}\right\}_{n=1}^\infty$ и $\left\{{\beta _n}\right\}_{n=1}^\infty$.

Приравнивая левые части этих равенств найдем, что

$a +\alpha _n=b +\beta _n$ или $\alpha _n-\beta _n=b-a$,

т.е. все элементы бесконечно малой последовательности $\left\{{\alpha _n-\beta _n}\right\}_{n=1}^\infty$ равны одному и тому же числу $b-a$. Следовательно, по лемме $b-a=0$, т.е $a=b$.

### Теорема об ограниченности сходящейся последовательности

Теорема. Сходящаяся последовательность ограничена.

Доказательство. Пусть $\lim\limits_{n\to\infty}x_n=a$, т.е. по определению

$\forall\;\;\varepsilon > 0\;\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n > n_0\;\Rightarrow\;\left| {x_n-a}\right| < \varepsilon$.

Тогда $\left| {x_n}\right|=\left| {\left( {x_n-a}\right) + a}\right|\leq\left| {x_n-a}\right| +\left| a\right| < \varepsilon +\left| a\right|$ для всех $n > n_0$.

Так как число элементов с номерами $n\leq n_0$ конечно, то можно найти элемент

$A=\max\left\{{\left| a\right| +\varepsilon ,\left| {x_1}\right|,\ldots ,\left| {x_{n_0}}\right|}\right\}$.

Очевидно, что для всех $n$ выполняется неравенство $\left|x_n\right|\leq A$, следовательно, последовательность $\left\{{x_n}\right\}_{n=1}^\infty$– ограничена.

Замечание. Из ограниченности последовательности не следует ее сходимость. Так, например, последовательность $\left\{{\left( {-1}\right)^n}\right\}_{n=1}^\infty$ является ограниченной, но не является сходящейся. Покажем это.

От противного. Пусть все же последовательность сходится и $\lim\limits_{n\to\infty}\left( {-1}\right)^n=a$, тогда по определению

$\forall\;\;\varepsilon > 0\;\;\exists\;n_0\left(\varepsilon\right)\;:\;\forall\;n > n_0\;\Rightarrow\;\left| {\left( {-1}\right)^n-a}\right| < \varepsilon$ и для $\varepsilon=\frac{1}{2}$

начиная с некоторого номера выполняется неравенство

$\left| {\left( {-1}\right)^n-a}\right| < \frac{1}{2}$.

Так как элементы последовательности поочередно принимают значения 1 и –1, то верны неравенства

$\left| {1-a}\right| < \frac{1}{2}$ и $\left| {-1-a}\right| < \frac{1}{2}$.

Используя эти неравенства, получаем

$2=\left| {1-a-\left( {-1-a}\right)}\right|\leq\left| {1-a}\right| +\left| {-1-a}\right| < \frac{1}{2}+\frac{1}{2}= 1$,

т.е. $2 < 1$. Полученное противоречие и доказывает расходимость данной последовательности.

### Теорема об арифметике пределов последовательностей

Теорема об арифметике пределов последовательностей.

Пусть $\lim\limits_{n \to \infty } a_n = a$ и $\lim\limits_{n \to \infty } b_n = b$ , тогда:

• $\lim\limits_{n \to \infty } \alpha a_n = \alpha a$ для любого действительного числа $\alpha$ ;
• $\lim\limits_{n \to \infty } \left( {a_n \pm b_n } \right) = a \pm b$ ;
• $\lim\limits_{n \to \infty } \left( {a_n \cdot b_n } \right) = a \cdot b$ ;
• $\lim\limits_{n \to \infty } \frac{{a_n }}{{b_n }} = \frac{a}{b}$ , если $b \neq 0$ .
Лемма. Если последовательность $\left\{ {b_n } \right\}_{n = 1}^\infty$ сходится, то последовательность $\left\{ {\frac{1}{{b_n }}} \right\}_{n = 1}^\infty$ , начиная с некоторого номера $n$ , является ограниченной.

Доказательство. Так как последовательность $\left\{ {b_n } \right\}_{n = 1}^\infty$ сходится, то по определению предела последовательности

$\forall \,\,\varepsilon > 0\,\,\,\exists \,\,\,n_0 \left( \varepsilon \right)\,\,:\,\,\forall \,\,n > n_0 \,\,\, \Rightarrow \,\,\,\left| {b_n - b} \right| < \varepsilon$ ,

в качестве $\varepsilon$ выберем $\left| {\frac{b}{2}} \right|$ :

$\left| {b_n - b} \right| < \left| {\frac{b}{2}} \right|$ .

Отсюда

$\left| b \right| = \left| {b - b_n + b_n } \right| < \left| {b - b_n } \right| + \left| {b_n } \right| < \left| {\frac{b}{2}} \right| + \left| {b_n } \right|$ ,

следовательно, $\left| {\frac{b}{2}} \right| < \left| {b_n } \right|$ . Тогда $\left| {\frac{1}{{b_n }}} \right| < \left| {\frac{2}{b}} \right|$ , что означает, что последовательность $\left\{ {\frac{1}{{b_n }}} \right\}_{n = n_0 + 1}^\infty$ является ограниченной. Лемма доказана.

Доказательство теоремы. Докажем свойство 4 теоремы об арифметике.

Покажем, что $\lim\limits_{n \to \infty } \frac{{a_n }}{{b_n }} = \frac{a}{b}$ , т.е. последовательность $\left\{ {\frac{{a_n }}{{b_n }} - \frac{a}{b}} \right\}$ –бесконечно малая. Так как $\lim\limits_{n \to \infty } a_n = a$ и $\lim\limits_{n \to \infty } b_n = b$ , то по определению предела $a_n = a + \alpha _n$ и $b_n = b + \beta _n$ , где $\alpha _n$ и $\beta _n$ бесконечно малые последовательности. Тогда

$\left\{ {\frac{{a_n }}{{b_n }} - \frac{a}{b}} \right\} = \left\{ {\frac{1}{{b_n }} \cdot \frac{{b\left( {a + \alpha _n } \right) - a\left( {b + \beta _n } \right)}}{b}} \right\} = \left\{ {\frac{1}{{b_n }}} \right\}\left\{ {\frac{{b\alpha _n - a\beta _n }}{b}} \right\}$.

По теореме об арифметике бесконечно малых последовательность $\left\{ {\frac{{b\alpha _n - a\beta _n }}{b}} \right\}$ является бесконечно малой, а последовательность $\left\{ {\frac{1}{{b_n }}} \right\}$ является ограниченной по доказанной лемме, начиная с некоторого номера $n$ . Таким образом, последовательность $\left\{ {\frac{{a_n }}{{b_n }} - \frac{a}{b}} \right\}$ является бесконечно малой, как произведение ограниченной на бесконечно малую. Теорема доказана.

Пример 6. Вычислить предел $\lim\limits_{n\to\infty}\frac{n}{n+1}$.

Р е ш е н и е. Числитель и знаменатель дроби стремятся к $\infty$, имеем неопределенность $\left[\frac{\infty}{\infty}\right]$. Разделим числитель и знаменатель на $n$:

$\lim\limits_{n\to\infty}\frac{n}{n+1}=\lim\limits_{n\to\infty}\frac{1}{1+\frac1n}$.

Дробь $\frac{1}{n}\to 0$ при $n\to\infty$, следовательно, знаменатель дроби

$\left(1+\frac1n\right)\to1$ и $\lim\limits_{n\to\infty}\frac{1}{1+\frac1n}=1$.

### Примеры вычисления пределов

Пример 7. Вычислить предел $\lim\limits_{n \to \infty } \frac{{3{n^2} + 10n + 4}}{{{n^2} + 1}}$.

Р е ш е н и е. На бесконечности числитель и знаменатель дроби стремятся к бесконечности, т.е. имеем неопределенность:

$\lim\limits_{n \to \infty } \frac{{3{n^2} + 10n + 4}}{{{n^2} + 1}} = \left[ {\frac{\infty }{\infty }} \right]$

Для раскрытия неопределенности вынесем за скобки в числителе и знаменателе $n$ в старшей степени:

$\lim\limits_{n \to \infty } \frac{{3{n^2} + 10n + 4}}{{{n^2} + 1}} = \left[ {\frac{\infty }{\infty }} \right] = \lim\limits_{n \to \infty } \frac{{{n^2}\left( {3 + \frac{{10}}{n} + \frac{4}{{{n^2}}}} \right)}}{{{n^2}\left( {1 + \frac{1}{{{n^2}}}} \right)}}$.

Величины $\frac{{10}}{n},\;\frac{4}{{{n^2}}},\;\frac{1}{{{n^2}}}$ являются бесконечно малыми при $n \to \infty$, т.е. стремятся к нулю, следовательно:

$\lim\limits_{n \to \infty } \frac{{{n^2}\left( {3 + \frac{{10}}{n} + \frac{4}{{{n^2}}}} \right)}}{{{n^2}\left( {1 + \frac{1}{{{n^2}}}} \right)}} = \lim\limits_{n \to \infty } \frac{{3{n^2}}}{{{n^2}}} = 3$.

Факториалом натурального числа $n$ называется натуральное число $n!$, равное произведению чисел от 1 до $n$:

$n! = 1 \cdot 2 \cdot 3 \cdot \ldots \cdot n$.

Очевидны равенства

$\left( {n + 1} \right)! = 1 \cdot 2 \cdot 3 \cdot \ldots \cdot n \cdot \left( {n + 1} \right) = n!\left( {n + 1} \right)$

$\left( {n + 2} \right)! = 1 \cdot 2 \cdot 3 \cdot \ldots \cdot n \cdot \left( {n + 1} \right)\left( {n + 2} \right) = n!\left( {n + 1} \right)\left( {n + 2} \right) = \left( {n + 1} \right)!\left( {n + 2} \right)$.

Пример 8. При вычислении пределов последовательностей, содержащих разные факториалы, необходимо выразить все факториалы через самый младший:

$\lim\limits_{n \to \infty } \frac{{n!}}{{\left( {n + 1} \right)! - n!}} = \lim\limits_{n \to \infty } \frac{{n!}}{{n!\left( {n + 1} \right) - n!}} = \lim\limits_{n \to \infty } \frac{{n!}}{{n!\left( {\left( {n + 1} \right) - 1} \right)}} = \lim\limits_{n \to \infty } \frac{1}{n} = 0$.

### Эквивалентные последовательности

Последовательности $\left\{ {a_n } \right\}_{n = 1}^\infty$ и $\left\{ {b_n } \right\}_{n = 1}^\infty$ называются эквивалентными, если

$\lim\limits_{n \to \infty } \frac{{a_n }}{{b_n }}=1$.

Эквивалентные последовательности обозначаются $a_n\sim b_n$.

Например, последовательности $\left\{ {n } \right\}_{n = 1}^\infty$ и $\left\{ {n+1 } \right\}_{n = 1}^\infty$, а так же последовательности $\left\{ {\frac{1}{n}} \right\}_{n = 1}^\infty$и $\left\{ {\frac{1}{{n + 1}}} \right\}_{n = 1}^\infty$ эквивалентны, так как

$\lim\limits_{n \to \infty } \frac{{n}}{{n+1}}=1$ и $\lim\limits_{n \to \infty } \frac{{\frac{1}{n}}}{{\frac{1}{{n + 1}}}} = \lim\limits_{n \to \infty } \frac{{n + 1}}{n} = \lim\limits_{n \to \infty } \left( {1 + \frac{1}{n}} \right) = 1$.

Аналогично, многочлен $a_0n^k+a_1n^{k-1}+\ldots+a_n$ эквивалентен слагаемому, содержащему старшую степень $n$, то есть

$a_0n^k+a_1n^{k-1}+\ldots+a_n\sim a_0n^k$, так как $\lim\limits_{n \to \infty } \frac{{a_0 n^k + a_1 n^{k - 1} + \ldots + a_n }}{{a_0 n^k }} = \lim\limits_{n \to \infty } \frac{{a_0 + a_1 \frac{1}{n} + \ldots + a_n \frac{1}{{n^k }}}}{{a_0 }} = 1$.

Поэтому при нахождении пределов, содержащих действия с многочленами, слагаемые с младшими степенями можно отбросить (только не в разности эквивалентных!) :

$\lim\limits_{n \to \infty } \frac{\left({\sqrt{n^2+1}+n}\right)^2}{{n^2+1}}=\lim\limits_{n \to \infty } \frac{\left({\sqrt{n^2}+n}\right)^2}{{n^2}}=\lim\limits_{n \to \infty } \frac{\left(2n\right)^2}{{n^2}}=\lim\limits_{n \to \infty } \frac{4n^2}{{n^2}}=4$.

Пример 9. Вычислим предел $\lim\limits_{n \to \infty } \frac{{\sqrt {4{n^2} + 1} + n}}{{\root 3 \of {8{n^3} + {n^2} + 2} }}$.

Р е ш е н и е. Перейдем к эквивалентным величинам в числителе и знаменателе:

$4{n^2} + 1 \sim 4{n^2};\;\;8{n^3} + {n^2} + 2 \sim 8{n^3}$ при $n \to \infty$ ,

и вычислим предел:

$\lim\limits_{n \to \infty } \frac{{\sqrt {4{n^2} + 1} + n}}{{\root 3 \of {8{n^3} + {n^2} + 2} }} = \lim\limits_{n \to \infty } \frac{{\sqrt {4{n^2}} + n}}{{\root 3 \of {8{n^3}} }} = \lim\limits_{n \to \infty } \frac{{3n}}{{2n}} = \frac{3}{2}$ .

### Внимание!

Пример 10. Вычислим предел $\lim\limits_{n \to \infty } \frac{{{{\left( {2n + 1} \right)}^3} - {{\left( {n - 1} \right)}^3}}}{{{{\left( {n + 1} \right)}^4} - {{\left( {n - 1} \right)}^4}}}$

Р е ш е н и е. В числителе можно перейти к эквивалентным бесконечно большим, но в знаменателе такой переход «превратит» разность бесконечно больших в выражение, тождественно равное нулю:

${\left( {n + 1} \right)^4} - {\left( {n - 1} \right)^4} \sim {n^4} - {n^4} = 0$ НЕВЕРНО!

Преобразуем разность в знаменателе, раскрывая степени:

${\left( {n + 1} \right)^4} - {\left( {n - 1} \right)^4} = \left( {{{\left( {n + 1} \right)}^2} - {{\left( {n - 1} \right)}^2}} \right)\left( {{{\left( {n + 1} \right)}^2} + {{\left( {n - 1} \right)}^2}} \right) =$

$= \left( {{n^2} + 2n + 1 - \left( {{n^2} - 2n + 1} \right)} \right)\left( {{{\left( {n + 1} \right)}^2} + {{\left( {n - 1} \right)}^2}} \right) = 4n\left( {{{\left( {n + 1} \right)}^2} + {{\left( {n - 1} \right)}^2}} \right) \sim 4n \cdot 2{n^2} = 8{n^3}$,

и вычислим предел:

$\lim\limits_{n \to \infty } \frac{{{{\left( {2n + 1} \right)}^3} - {{\left( {n - 1} \right)}^3}}}{{{{\left( {n + 1} \right)}^4} - {{\left( {n - 1} \right)}^4}}} = \lim\limits_{n \to \infty } \frac{{{{\left( {2n} \right)}^3} - {{\left( n \right)}^3}}}{{8{n^3}}} = \lim\limits_{n \to \infty } \frac{{7{n^3}}}{{8{n^3}}} = \frac{7}{8}$.

Пример 11. Вычислим предел $\lim\limits_{n \to \infty } \left( {\frac{{{n^2}}}{{n + 1}} - \frac{{{n^3}}}{{{n^2} + 1}}} \right)$

Р е ш е н и е. Перейти к эквивалентным в знаменателях дробей нельзя, так как при этом:

$\frac{{{n^2}}}{{n + 1}} - \frac{{{n^3}}}{{{n^2} + 1}} \sim \frac{{{n^2}}}{n} - \frac{{{n^3}}}{{{n^2}}} = n - n \equiv 0$ НЕПРАВИЛЬНО!

Преобразуем разность дробей, переходя к общему знаменателю:

$\lim\limits_{n \to \infty } \left( {\frac{{{n^2}}}{{n + 1}} - \frac{{{n^3}}}{{{n^2} + 1}}} \right) = \lim\limits_{n \to \infty } \frac{{{n^2}\left( {{n^2} + 1} \right) - {n^3}\left( {n + 1} \right)}}{{\left( {n + 1} \right)\left( {{n^2} + 1} \right)}} = \lim\limits_{n \to \infty } \frac{{{n^4} + {n^2} - {n^4} - {n^3}}}{{n \cdot {n^2}}} =$

$= \lim\limits_{n \to \infty } \frac{{{n^2} - {n^3}}}{{{n^3}}} = \lim\limits_{n \to \infty } \frac{{ - {n^3}}}{{{n^3}}} = - 1$ .
