# DIBot — локальный учебный ассистент

Помогает учиться по материалам НГТУ: читает лекции и методички, собирает
конспекты со ссылками на источник, разбирает задачи «как в тетради» и
проверяет собственные решения. Всё считается локально, в Ollama.

## Чего DIBot не делает

Это осознанная граница, а не недоделка:

- не проходит тесты и контрольные вместо студента;
- не имитирует «человеческое» время, чтобы обойти контроль;
- не обходит антибот-защиту и не хранит пароль от диспейса.

Читалка диспейса только читает страницы. Вход выполняет сам пользователь
в открытом окне браузера, пароль вводится в браузере и скрипту не доступен.

## Что нужно

- Windows 10/11, Python 3.11+;
- Ollama 0.40+ с моделями (около 21 ГБ);
- видеокарта от 8 ГБ VRAM (проверено на RTX 4060 8 ГБ);
- Docker Desktop — только для быстрого веб-поиска через SearXNG.

## Установка

```powershell
cd D:\DIBot
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium

ollama pull qwen3.5:9b
ollama pull deepseek-r1:8b
ollama pull qwen2.5-coder:7b
ollama pull qwen3-vl:8b
```

Модели можно хранить не на системном диске:

```powershell
setx OLLAMA_MODELS "D:\OllamaModels"
```

После этого перезапустите Ollama. Проверка:

```powershell
python src/check_llm.py
```

## Быстрый старт

### 1. Добавить материалы

```powershell
# один файл (.txt, .md, .pdf)
python src/ingest.py --course "Линейная алгебра" --title "Лекция 1" --file data/samples/lecture_matrices.txt

# папка целиком и сразу конспект
python src/ingest.py --dir data/samples --course "Линейная алгебра" --notes

# что уже загружено
python src/ingest.py --list

# пересобрать конспект для существующего источника
python src/ingest.py --notes-for "линейная-алгебра-лекция-1-матрицы-и-определители"
```

### 2. Запустить интерфейс

```powershell
streamlit run src/app.py
```

Откроется `http://localhost:8501`. Вкладки: чат, материалы, конспекты,
тренажёр, модели.

### 3. Веб-поиск (необязательно)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_searxng.ps1
```

SearXNG поднимется на `http://localhost:8080`. Остановка: `docker compose down`.

### 4. Читалка диспейса

```powershell
python src/lms_reader.py --login          # войти вручную, сессия сохранится
python src/lms_reader.py --courses        # список курсов
python src/lms_reader.py --read "https://dispace.nstu.ru/course/..."
python src/lms_reader.py --links "https://dispace.nstu.ru/course/..."   # отладка навигации
python src/lms_reader.py --import "https://dispace.nstu.ru/course/..." --course "Линейная алгебра"
```

`dispace.nstu.ru` — SPA «Dicourse». Читалка берёт отрисованный текст страницы
и попутно запоминает JSON, который загружает само приложение. Если ссылки
курса не распознались, откройте нужную страницу через `--read` и передайте
её URL в `--import`.

После входа рядом с профилем сохраняются `data/browser_state.json` и
`data/browser_session_storage.json`. Это токены сессии — не передавайте их
никому и не выкладывайте в публичный репозиторий (`.gitignore` уже исключает
эти файлы).

## Проверка работы

```powershell
python scripts/test_verification.py   # 15 регрессионных кейсов sympy, без модели
python scripts/demo.py                # сквозной прогон: материалы → ответ → проверка
python scripts/demo.py --web          # то же с веб-поиском
```

### Маршрутизация моделей

| задача | модель | зачем |
|---|---|---|
| `chat` | qwen3.5:9b | объяснения, теория |
| `notes` | qwen3.5:9b | конспекты по фрагментам |
| `summary` | qwen3.5:9b | краткие выжимки |
| `math` | deepseek-r1:8b | пошаговые решения |
| `code` | qwen2.5-coder:7b | код и LaTeX |
| `latex` | qwen2.5-coder:7b | оформление формул |
| `vision` | qwen3-vl:8b | сканы и фото задач |
| `verify` | qwen3.5:9b | критика чужого решения |

Теоретические вопросы («что такое…», «объясни…») уходят в `chat`, а не в
reasoning-модель: иначе один вопрос считается минутами без пользы.

### Три слоя проверки

1. **sympy** — детерминированный пересчёт: определители, пределы,
   производные, интегралы, уравнения и системы, арифметика. Ловит арифметику,
   знаки, потерянные корни. Это не мнение модели.
2. **Кросс-модель** — решение критикует другая модель, обязательно не та,
   что решала. Ловит ошибки в рассуждении.
3. **Ссылки** — в конспекте каждый тезис несёт маркер фрагмента. Выдуманный
   тезис остаётся без ссылки, и это видно в отчёте о покрытии.

Вердикты честные: `ПОДТВЕРЖДЕНО`, `СПОРНО — не доверять`, `НЕ ПРОВЕРЕНО`.
Если проверить нечем, бот так и говорит, а не делает вид.

## Ограничения

- **8 ГБ VRAM.** Контекст ограничен 8192 токенами. При 16384 модель не
  влезает в видеопамять, часть слоёв уходит на CPU, скорость падает примерно
  в 8 раз. В памяти помещается одна 8B-модель, поэтому проверка идёт пакетно.
- **Читалка диспейса.** Эвристики разбора ссылок проверены на странице входа,
  но не на реальном личном кабинете. Если структура курса не распозналась,
  используйте `--read` + `--import`.
- **PDF.** Нужен текстовый слой. Сканы без текста требуют OCR через
  `qwen3-vl` — это пока не автоматизировано.

## Если что-то не работает

- **Ollama не отвечает.** Проверьте `python src/check_llm.py`; сервер должен
  слушать `http://localhost:11434`.
- **SearXNG отвечает 403 на JSON.** В `docker/searxng/settings.yml` в
  `search.formats` должен быть `json`.
- **PowerShell 5.1 ломает кириллицу в `.ps1`.** Файл нужно сохранять в UTF-8
  с BOM. Консольный вывод может выглядеть искажённым даже при корректном
  файле — проверяйте файлы редактором.
- **Медленные ответы.** Убедитесь, что `num_ctx` не больше 8192 и модель
  целиком в VRAM: `nvidia-smi`, затем `ollama ps` (должно быть `100% GPU`).
